## Day 24 — Advanced File I/O with `pathlib`

The `pathlib` module provides a modern, object-oriented replacement for `os.path`.

```python
from pathlib import Path
```

### Creating Paths

```python
Path("logs")
Path("logs/auth.log")
```

### Key Methods & Properties

| Method / Property | Description |
|-------------------|-------------|
| `exists()` | Check if the path exists |
| `is_file()` | Check if it's a file |
| `is_dir()` | Check if it's a directory |
| `absolute()` | Return the full absolute path |
| `glob("*.py")` | Match files in the current directory only |
| `rglob("*.log")` | Recursive glob — matches in all subdirectories |
| `suffix` | File extension (e.g., `.txt`, `.py`) |
| `stem` | Filename without extension (e.g., `report` from `report.log`) |
| `name` | Full filename (e.g., `report.log`) |

### `os.walk()` — Recursive Directory Traversal

Returns a 3-tuple: `(root, dirs, files)`

```python
import os

for root, dirs, files in os.walk(directory):
    # process each directory tree level
```

### `os.path.join()` — Safe Path Construction

Always use this instead of string concatenation:

```python
# Bad
folder + "/" + file

# Good
os.path.join(folder, file)
```

### `os.stat()` — File Metadata

Retrieve file information without opening it:

| Attribute | Meaning |
|-----------|---------|
| `st_size` | File size in bytes |
| `st_mtime` | Last modification time (timestamp) |

```python
import os
stats = os.stat("file.txt")
print(stats.st_size)
```

- Use **`Path.rglob()`** for recursive file searches.
- Use **`os.stat()`** to check file size instead of opening the file.
- Never use **string concatenation** to build file paths.

## Day 25 — CSV & JSON

### JSON (JavaScript Object Notation)

Standard format for data exchange.

| Function | Purpose |
|----------|---------|
| `json.dump(data, file)` | Write JSON to a file |
| `json.dumps(data)` | Convert object to JSON string |
| `json.load(file)` | Read JSON from a file |
| `json.loads(string)` | Parse JSON from a string |

#### Formatting Options

```python
json.dump(data, file, indent=4, ensure_ascii=False)
```

| Option | Effect |
|--------|--------|
| `indent=4` | Pretty-prints with 4-space indentation |
| `ensure_ascii=False` | Preserves Unicode characters (e.g., Arabic text) instead of `\uXXXX` escape sequences |

---

### CSV (Comma Separated Values)

| Class | Reads / Writes | Output Format |
|-------|----------------|---------------|
| `csv.reader()` | Reads rows as **lists** | `['192.168.1.1', 'FAILED']` |
| `csv.DictReader()` | Reads rows as **dictionaries** | `{'IP': '192.168.1.1', 'Status': 'FAILED'}` |
| `csv.writer()` | Writes from **lists** | — |
| `csv.DictWriter()` | Writes from **dictionaries** | — |

#### Writing with `DictWriter`

```python
import csv

fieldnames = ["IP", "Status", "Timestamp"]
writer = csv.DictWriter(file, fieldnames=fieldnames)

writer.writeheader()
writer.writerows(data)
```

> **Critical:** Always open CSV files with `newline=""` to prevent blank lines.

### Regex Patterns Used

| Field | Pattern |
|-------|---------|
| IP Address | `(\d{1,3}\.){3}\d{1,3}` |
| Timestamp | `\d{4}-\d{2}-\d{2} \S+` |
| Action | `(?<=- )\w+(?= -)` |
| Status | `\w+$` |

---

### JSON vs. CSV Comparison

| Feature | JSON | CSV |
|---------|------|-----|
| Nested data | Supported | Not supported |
| Best for | Programs / APIs | Spreadsheets (Excel) |
| Structure | Dictionaries & Lists | Rows & Columns |
| Flexibility | Highly flexible | Simple & fast |

---

### Common Mistakes

#### JSON
- Forgetting `ensure_ascii=False` (mangles non-ASCII text)
- Using `dumps()` instead of `dump()` when writing to files
- Forgetting `indent` (produces unreadable single-line output)

#### CSV
- Forgetting `newline=""` when opening the file
- Forgetting `writeheader()` with `DictWriter`
- Mismatch between `fieldnames` and dictionary keys
